# Climate Vulnerability and Resilience Assessment Toolkit: field site (prototype)

A phone-first, installable, offline-capable version of IPNLF's Climate Vulnerability and Resilience Assessment Toolkit for tuna fishing communities in Maluku and North Maluku.

**Draft for testing. Not for field use.** Public but kept out of search engines (robots meta tag and `robots.txt`). Removing both is a go-live step.

## Before any field use (outstanding)

- **Safeguarding:** the consent script promises full confidentiality, but there is no referral pathway or named safeguarding lead for disclosures of violence, forced labour or child labour.
- **Data protection:** devices, KoboToolbox hosting, data retention and compliance with Indonesia's Personal Data Protection Law (Law No. 27 of 2022) are undecided.

## How it is built

All guidance text comes word for word from the toolkit Word document. `content.json` is extracted from the `.docx` by `extract.py`; the page renders it. Do not edit `content.json` by hand: fix the Word document and re-extract.

Files here are generated by `build_pwa.py` from the source page (`index.html` + `content.json`) and the worker template `sw_template.js`. The source files and scripts are kept outside this repository, in the project's `Field Kit/website` folder.

- `index.html`: the whole site (no framework, no build step beyond `build_pwa.py`)
- `content.json`: the toolkit text
- `sw.js`: stores the site and fonts on the phone so it works offline; versioned by content, so a new build replaces the old copy the next time the phone is online
- `manifest.webmanifest` and icons: "Add to home screen"

Design variants for testing open directly with links such as `#home-va`, `#home-vb`, `#home-vc`, `#c5-vc`, `#c3-vb`, `#c7-va`.
